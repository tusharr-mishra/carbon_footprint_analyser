# Carbon Footprint Analyser

A Java-based console application that estimates a user's carbon footprint
based on their daily lifestyle inputs — transport, diet, energy usage, and habits.

Built as a mini project to practice object-oriented design and user input handling in Java.

---

## What It Does

- Takes structured user inputs across lifestyle categories
- Calculates an estimated carbon footprint score
- Displays output in a readable, categorized format
- Helps users understand which habits contribute most to emissions

## How to Run

```bash
git clone https://github.com/tusharr-mishra/carbon-footprint-analyser.git
cd carbon-footprint-analyser
javac Main.java
java Main
```

> Requires Java 8 or above. No external libraries needed.
